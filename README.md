# Task-Quiz

Тестовое задание на Unity: викторина, в которой нужно найти указанную цифру или букву среди карточек. Проект посвящён генерации игрового поля, работе со сменяемыми наборами данных и анимированной обратной связи.

**Стек:** C#, SpriteRenderer, Unity UI (uGUI), ScriptableObject, DOTween.

**Unity:** 2020.3.36f1 · **Сцена:** [SampleScene](Assets/Game/Scenes/SampleScene.unity).

## Условие задания

Краткое изложение [исходного задания](docs/TASK.md):

- Три последовательных уровня сложности: **3, 6 и 9 ячеек**. Игрок выбирает ответ на задание вида `Find F` или `Find 7`.
- При старте ячейки появляются с bounce-анимацией, а текст — с fade-in. Между уровнями содержимое и текст меняются мгновенно.
- Неправильный ответ вызывает покачивание объекта; правильный — bounce-анимацию и звёздочки на выбранной карточке.
- После третьего уровня поле блокируется, появляется полупрозрачное затемнение и кнопка **Restart**. Перезапуск проходит через загрузочный экран и возвращает к первому уровню.
- Набор данных и цель выбираются случайно. Правильный ответ на поле должен быть единственным, а цели — не повторяться в течение одного запуска Play Mode, включая перезапуски через Restart.
- Общая механика должна работать с любыми наборами изображений без отдельных веток для букв и цифр. Все уровни используют одну сцену и один префаб ячейки.

## Реализация

В конфигурации заданы поля **3 × 1, 3 × 2 и 3 × 3**. На каждом уровне выбирается один из двух наборов: **числа 1–10** или **буквы A–Z**. Карточки содержат спрайт и строковый идентификатор, из которого формируется задание.

Код размещает целевую карточку в случайной ячейке, затем заполняет остальные ячейки вариантами ответа. Выбор обрабатывается через `OnMouseDown`, ответ проверяется по идентификатору.

Для неверного ответа предусмотрено покачивание значка. Для верного — частицы и bounce-анимация; ввод блокируется, а через две секунды происходит переход дальше. После последнего уровня показывается Restart с затемнением. При перезапуске поле пересоздаётся через загрузочный экран; существующие ячейки используются повторно.

## Технические решения

- **Данные отделены от механики.** `CardsContainer` хранит набор карточек, а `LevelContainer` — размеры полей. Чтобы добавить новую тему, можно подготовить набор спрайтов и идентификаторов и подключить его к `LevelController`.
- **Генерация разделена на этапы.** `CellsFactory` объединяет построение сетки через `GridCreator` и заполнение карточек через `CardCreator`; выбор цели и проверка ответа находятся в `TaskHandler`.
- **Ячейки переиспользуются.** `ObjectPool<T>` хранит экземпляры единственного префаба `Cell` и возвращает неактивные при смене уровня.
- **Отображение отделено от управления.** Контроллеры уровня и ячейки обращаются к View-компонентам; эффекты масштаба, покачивания и прозрачности вынесены в обёртки над DOTween.
- **Подготовка контента автоматизирована.** `CardsContainer.OnValidate` может извлекать идентификаторы из имён спрайтов по регулярному выражению. Признак поворота в имени спрайта учитывается при отображении.
- **Код разделён на сборки по назначению.** Карточки, ячейки, генерация поля, уровни, эффекты, обработка кликов и загрузка имеют отдельные asmdef.

## Текущее состояние

При чтении исходников обнаружены расхождения, которые нужно учитывать перед запуском:

- В `CellController` свойство называется `IsÑlickable`, а `LevelController` обращается к `IsСlickable`. Это разные Unicode-символы в имени; обращение к отсутствующему свойству препятствует компиляции.
- `TaskHandler.SelectTask()` выбирает цель без проверки истории, а Restart очищает историю. Требование о неповторении целей на протяжении Play Mode пока не выполнено.
- Числовой набор содержит **1–10**, хотя в исходном задании указан диапазон **1–9**.

Описание реализации составлено по коду и конфигурации; запуск в Unity и визуальные эффекты не проверены.
